1. Wat doet de tool?

De FLIM-tool gebruikt twee invoerbestanden. Deze tool maakt ze automatisch opnieuw met actuele cijfers:

BestandInhoudBron
material_market_share.xlsx Per materiaal: uit welke landen Nederland importeert en welk aandeel elk land heeft (opgeteld 1). UN Comtrade
prijzen.xlsx Per materiaal een maandelijkse prijsindex, gelijk aan 1 in de startmaand. CBS, Destatis, FRED, Eurostat

Je levert alleen een lijst met materialen en codes aan. De tool haalt de cijfers op, zet ze in het juiste formaat en laat per code zien wat gelukt is en wat niet.

2. In het kort: een update in 5 stappen

  1. Download het voorbeeldbestand op de hoofdpagina en vul het aan of pas het aan. Het bevat de huidige materialen met hun codes en FLIM-ID's.
  2. Upload het bestand. De tool controleert het meteen en toont fouten (rood) en waarschuwingen (geel). Met een fout kun je niet starten; waarschuwingen zijn ter informatie.
  3. Kies de instellingen: welke bronnen, het jaar voor de importcijfers en de startmaand voor de prijzen.
  4. Klik op Start update en volg de voortgang. Een volledige run duurt meestal een paar minuten.
  5. Download de bestanden zodra de run klaar is. Controleer de melding bovenaan het resultaat en rapport.xlsx op mislukte codes.

De bestanden blijven alleen bewaard tot de server herstart. Download ze daarom direct. Er kan maar één update tegelijk lopen; start iemand anders er al een, dan krijg je een melding.

3. Het invoerbestand

Eén Excel-bestand (.xlsx) met een blad per bron. De bladnaam bepaalt de bron: hij moet Comtrade, CBS, Destatis, FRED of Eurostat bevatten (hoofdletters maken niet uit). Andere bladen, zoals Uitleg, worden overgeslagen. Op elk blad staan de kolomkoppen in de eerste rij; de volgorde van de kolommen maakt niet uit, de namen wel.

BladVerplichte kolommenOptionele kolommenVoorbeeldcode
ComtradeMateriaal, CodeOmschrijving440792 (HS-code)
CBSMateriaal, CodeID, Prijs237 (ProdCom/CPA)
DestatisMateriaal, CodeID, TabelGP19-237011
FREDMateriaal, CodeIDPCU327991327991
EurostatMateriaal, CodeID, LandC237 (NACE)

Extra kolommen (zoals Thema of Opmerking) mag je toevoegen; de tool negeert ze.

Regels die je moet kennen

  • ID is het FLIM-materiaal-ID en komt in rij 1 van prijzen.xlsx. Elke combinatie van materiaal en bron heeft een eigen, uniek ID. Heeft Marble een CBS- én een FRED-reeks, dan zijn dat twee ID's. Een ontbrekend of dubbel ID geeft een waarschuwing.
  • Materiaalnamen zijn in beide uitvoerbestanden gelijk aan wat je invult. Gebruik dus dezelfde spelling als in FLIM en als op het Comtrade-blad.
  • Comtrade: zelfde naam, meerdere codes. Dan worden de importen van die codes opgeteld tot één marktaandeel. Wil je aparte materialen, geef ze dan een andere naam.
  • Prijsbronnen: zelfde code bij meerdere materialen mag. Ze krijgen dezelfde reeks, elk onder hun eigen ID.
  • Voorloopnullen: zet codes als tekst in Excel. Excel maakt van 0811 anders 811. Bij Comtrade vult de tool een weggevallen nul aan; bij CBS krijg je een waarschuwing.
  • Rijen zonder code worden overgeslagen (met een waarschuwing).

4. De bronnen en welke je kiest

De vier prijsbronnen meten niet hetzelfde. Kies per materiaal de bron die het best past bij wat FLIM moet laten zien.

CBS in detail

  • Code: de ProdCom/CPA-code zoals CBS die schrijft, bv. 237 (bewerkte natuursteen), 2331 (keramische tegels), 2351 (cement), 2361 (betonproducten), 2311 (vlakglas).
  • Prijs (optioneel): verbruik (standaard), invoer, binnenland, buitenland of afzet.
  • De huidige CBS-tabel (85770NED) begint in 2018. De tool koppelt hem automatisch aan de oudere tabel (83935NED, 2012–2023), zodat reeksen vanaf 2015 beschikbaar zijn. Bij de koppeling wordt het oude deel zo geschaald dat het in 2018 naadloos aansluit; vanaf 2018 gelden altijd de nieuwe cijfers. In de voortgang en op het blad Bronnen staat welke maanden uit de oude tabel komen.

Eurostat in detail

  • Code: een NACE-code, bv. C237, C25. Dataset: sts_inppd_m (producentenprijzen, binnenlandse markt, per maand).
  • Land (optioneel): bv. NL, DE. Leeg = de instelling Eurostat-land (standaard EU27_2020).
  • Niet elke code heeft cijfers voor elk land. Kies dan een bredere code (bv. C231 in plaats van C2311) of een ander land.

Destatis in detail

  • Code: GP19- gevolgd door cijfers, bv. GP19-0811, GP19-237011 of GP19-233110002. De tool zoekt elke code op in de codelijsten van Destatis en kiest zelf het juiste niveau (2-, 3-, 4-, 5-, 6-cijfercodes of geselecteerde 9-cijfercodes).
  • Streepjes: Destatis schrijft sommige codes met -- (bv. GP19--052010000). Je mag zowel - als -- gebruiken; de tool vindt de schrijfwijze van Destatis.
  • Een code die niet bij Destatis bestaat, mislukt meteen. De melding noemt codes die er wel op lijken.
  • Tabel (optioneel): standaard 61241-0004.

6. Voortgang lezen

Per bron zie je een balk en tellers; daaronder staat per code de status met een toelichting.

StatusBetekenis
wachtNog niet aan de beurt.
bezigWordt nu opgehaald.
opgehaaldComtrade: antwoord binnen, wordt aan het eind verwerkt.
geluktData opgehaald; de melding zegt hoeveel maanden of partnerlanden.
geen dataDe bron antwoordde, maar zonder cijfers (bv. geen import in dat jaar).
misluktEr ging iets mis; de melding zegt wat. Is een melding ingekort, beweeg er dan overheen voor de volledige tekst.

Met Alleen problemen filter je op mislukt en geen data. Onder Log staat elke stap met tijd. Met Afbreken stop je een run; wat al is opgehaald gaat dan verloren.

7. De uitvoerbestanden

prijzen.xlsx

  • Datasheet: rij 1 = ID, rij 2 = materiaal, kolom A = maand. Waarden zijn gedeeld door de waarde in de startmaand, dus de startmaand is 1. Dit blad leest FLIM.
  • Ruwe indices: dezelfde reeksen zoals de bron ze levert (niet genormaliseerd).
  • Bronnen: per reeks de bron, code, tabel/land/prijssoort, status, eerste en laatste maand, basismaand en meldingen (bv. over de CBS-koppeling).

Mist een reeks de startmaand (bv. een CBS-code die pas in 2018 begint), dan wordt hij op zijn eerste maand genormaliseerd en krijg je een waarschuwing. Zo'n reeks is niet goed vergelijkbaar met de rest; kies liever een andere code.

material_market_share.xlsx

Kolommen Materiaal2, partnerISO (landcode) en market_share, per materiaal gesorteerd van groot naar klein; de aandelen tellen per materiaal op tot 1. "World" (W00) is weggelaten.

rapport.xlsx

Status en melding per code, de gebruikte instellingen en de volledige log. Handig om te bewaren bij een update of om problemen door te sturen.

Mislukte codes ontbreken in de uitvoer. Controleer daarom altijd de melding bovenaan het resultaat.

9. Problemen oplossen

"Geen bladen gevonden met de naam Comtrade, CBS, …"
Hernoem de bladen zodat de naam van de bron erin staat, of begin met het voorbeeldbestand.
"kolom 'Materiaal' en 'Code' niet gevonden"
De kolomkoppen moeten in de eerste rij staan. De melding laat zien welke koppen wel gevonden zijn.
Een bron staat rood met "sleutel ontbreekt"
De API-sleutel van die bron is niet ingesteld op de server. Vraag de beheerder (zie hieronder). De andere bronnen werken gewoon.
"staat niet in CBS-tabel"
Controleer de code in StatLine. Let op een weggevallen voorloopnul.
Eurostat: "does not know this value of nace_r2 / geo"
De code of het land bestaat niet in de dataset. Controleer de schrijfwijze (bv. C237, NL).
Eurostat: "has no values for this code and country"
De combinatie bestaat, maar er zijn geen cijfers. Kies een bredere code of een ander land.
Destatis: "does not exist in Destatis table"
Destatis kent deze code niet. Controleer de code; de melding noemt codes die er wel op lijken.
Destatis: "has no GP19 variable for N-digit codes"
De codelijsten van Destatis waren niet te lezen en het aantal cijfers past bij geen enkel niveau. Probeer het later opnieuw of controleer de code.
Comtrade: veel codes "geen data"
Het gekozen jaar is waarschijnlijk nog niet (volledig) gepubliceerd. Kies een jaar eerder.
Comtrade: "STOPPING" of "server asks to wait"
De dagelijkse limiet van de API-sleutel is bereikt of de dienst is tijdelijk niet beschikbaar. Probeer het later opnieuw.
"Er loopt al een update"
Er kan maar één run tegelijk. Wacht tot die klaar is; open de hoofdpagina om de lopende run te volgen.
Mijn resultaat is weg
Na een herstart of nieuwe deploy van de server zijn eerdere runs weg. Start de update opnieuw.

10. Voor beheerders

De tool draait als Docker-container (Railway, later Azure). Instellingen gaan via omgevingsvariabelen (Railway: Variables; Azure: App Settings, eventueel met Key Vault-verwijzingen):

VariabeleDoel
COMTRADE_API_KEYSleutel voor UN Comtrade.
DESTATIS_TOKENToken voor Destatis GENESIS-Online (of DESTATIS_USER + DESTATIS_PASSWORD).
FRED_API_KEYSleutel voor FRED.
APP_PASSWORDZet een wachtwoord op de tool (sterk aanbevolen; de URL is openbaar).
APP_USERNAMEGebruikersnaam bij dat wachtwoord (standaard hva).

CBS en Eurostat hebben geen sleutel nodig. Draai de tool met één instantie: lopende runs en resultaten staan in het geheugen. Technische details staan in de README van de repository.
